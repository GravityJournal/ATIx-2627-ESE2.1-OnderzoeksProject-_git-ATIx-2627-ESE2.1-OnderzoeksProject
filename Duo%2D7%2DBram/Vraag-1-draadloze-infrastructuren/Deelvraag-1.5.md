      
#Deelvraag 1.5
Welke draadloze infrastructuur geeft de beste datadoorvoer en welke het minst?

Deze vraag is relevant omdat de verschillende infrastructuren vergeleken worden met elkaar en zo kunnen zien wat we het beste kunnen gebruiken.

om deze vraag te beantwoorden kijken we naar de datadoorvoer van van de verschillende draadloze infrastructuren.

| infrastructuur | datadoorvoer |
| --- | --- |
| 4g LTE | 0,3 Gbps |
| 4g LTE-Advanced | 1 Gbps |
| 4g LTE-Advanced Pro | ~ |
| 5g release 15 | 10-15 Gbps |
| 5g release 16 | 10-20 Gbps |
| 5g release 17 | 20 Gbps |
| 5g release 18 | 30+ Gbps |
| wifi 5 | 6,9 Gbps |
| wifi 6 | 9,6 Gbps |
| wifi 6e | 9,6 Gbps |
| wifi 7 | 30-40 Gbps |

#Conclusie
hieruit kunnen we concluderen dat wifi 7 de hoogste datadoorvoer bied met 30-40 Gbps en 5g release 18 als 2e komt met een datadoorvoer van 30+ Gbps
