Requirements over wat gebruikers moeten kunnen doen.
| CODE | REQUIREMENT | MoSCoW |
| --- | --- | --- |
| GE-01 | Een operator moet de status van het systeem kunnen bekijken via een Graphical User Interface | MUST |
| GE-02 | Een operator moet de status van de machines kunnen herkennen aan de signalering op de robots. | MUST |
| GE-03 | Een operator op de rooier moet de lineaire snelheid van een overslagwagen handmatig kunnen aanpassen wanneer deze naast de rooier rijdt. | MUST |
| GE-04 | Een operator aan de rand van het veld moet de lineaire snelheid van een overslagwagen handmatig kunnen aanpassen wanneer het lost. | MUST |
| GE-05 | Een operator aan de rand van het veld moet de angulaire snelheid van een overslagwagen handmatig kunnen aanpassen wanneer het lost. | MUST |
| GE-06 | Een operator moet de handmatige besturing van een overslagwagen met een afstandsbediening kunnen overnemen. | MUST |
