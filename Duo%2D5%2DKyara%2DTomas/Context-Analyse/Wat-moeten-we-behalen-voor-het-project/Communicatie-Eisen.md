Requirements over de communicatie tussen machines (centrale controller, overslagwagens, rooier en operator interface)
| CODE | REQUIREMENT | MoSCoW |
| --- | --- | --- |
| COM-01 | De centrale controller moet de positie van de rooier en overslagwagens sturen naar de overslagwagens | MUST |
| COM-02 | De centrale controller moet de status van de rooier en overslagwagens sturen naar de operator interface | MUST |
| COM-03 | De machines moeten informatie uitwisselen die nodig is om het overladen tussen de rooier en een overslagwagen te coördineren. | MUST |
| COM-04 | Het systeem moet de handmatige besturing van een overslagwagen mogelijk maken wanneer de operator de besturing overneemt. | MUST |
